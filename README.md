NovaRetail AI-Assisted Executive QBR Automation
Overview
This capstone project demonstrates an end-to-end automated workflow for generating a five-slide executive Quarterly Business Review (QBR) presentation for NovaRetail.

The solution combines Python-based data analysis, automated chart generation, Google ADK with Gemini for executive content generation, icon selection, and programmatic PowerPoint generation using the provided fixed template.

End-to-End Workflow
The automated workflow is:

Excel Dataset → Data Analysis → KPI Calculation → Chart Generation → Icon Selection → Google ADK / Gemini Content Generation → PowerPoint Template Population → Final Executive Presentation

The complete workflow can be executed from the project root using:

python main.py

Data Analysis
Pandas is used to analyze the three supplied business datasets:

Regional Performance
Customer Experience
Operational Risk
Business KPIs and comparisons are calculated programmatically before the information is passed to the AI model.

This helps ensure that business calculations are deterministic and that the AI model is used primarily for interpretation and executive content generation.

Chart Generation
Matplotlib is used to programmatically create presentation-ready visualizations including:

Regional revenue trend
Net Promoter Score trend
Regional stockout risk
The generated charts are saved in the charts directory and later inserted into the PowerPoint template.

Icon Selection
The supplied visual assets are mapped programmatically to the presentation topics.

Examples include:

Executive Summary → Globe / Region
Regional Performance → Growth Chart
Customer Experience → Customer Star
Operational Risk → Risk Alert
Recommended Actions → Lightbulb
Google ADK and Gemini
Google ADK is used to orchestrate AI-assisted executive content generation.

The agent receives verified metrics generated by the Python analysis workflow and creates concise executive presentation content for the five-slide QBR.

The agent is instructed to use the supplied metrics and avoid inventing or changing business figures.

Generated content is stored in:

output/slide_content.json
PowerPoint Automation
python-pptx is used to generate the final presentation from the provided fixed PowerPoint template.

The workflow uses the template's existing shapes, positions and dimensions to populate:

Executive summary
KPI values
Headlines
Business insights
Charts
Icons
Recommended actions
The original five-slide structure is retained.

Installation
Create and activate a Python virtual environment.

Install the required Python packages:

pip install -r requirements.txt
Configuration
The solution uses the Google Cloud configuration supplied for the training environment.

Create a .env file in the project root and configure the environment according to the training setup.

Required configuration:

GOOGLE_GENAI_USE_ENTERPRISE=TRUE
GOOGLE_CLOUD_PROJECT=<YOUR_TRAINING_PROJECT>
GOOGLE_CLOUD_LOCATION=<YOUR_TRAINING_LOCATION>
Do not commit .env, API keys, credentials, tokens, or other authentication information to GitHub.

The .env file is excluded through .gitignore.

Running the Complete Workflow
Activate the virtual environment and run:

python main.py
The master script executes the complete pipeline:

Data analysis
Chart generation
Icon selection
AI content generation
PowerPoint generation
Output
The final executive presentation is generated at:

output/NovaRetail_QBR_Final.pptx
Intermediate structured outputs are also available in the output directory.
